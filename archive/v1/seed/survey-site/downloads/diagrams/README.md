# Digital Twins: Visual Vocabulary

Ten domain symbols in distinct pastel colors, selected for the large-scale digital twins survey.

- `Digital-Twins-Visual-Vocabulary.html`: standalone reference sheet.
- `themes.json`: labels, symbols, colors, alternatives and icon provenance.
- `themes.css`: reusable CSS color variables.
- `icons/`: pastel SVG icons, each embedding its licensed source PNG; originals are in `originals/`.
- `digital-twins-landscape.svg`: conceptual relationship diagram; no quantitative flows.
- `digital-twins-visual-key.svg`: ten-domain visual key.

The ten theme icons are by their named creators via Noun Project, licensed CC BY 3.0; the communications icon is public domain. Preserve attribution and source/license links when reusing. Icons have been recolored to the theme palette. Colored SVG wrappers preserve the original PNG contours, and diagrams embed these colored icons. For editable vector icon source, use the linked creator pages and their offered download terms.
