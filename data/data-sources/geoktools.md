It is one of two Geospatial Reasoning Benchmarks released with Google Research's technical report on the Google Earth AI Geospatial Reasoning Agent (arXiv 2610.15750, submitted 11 October 2026).[^1,2,3] Each query is generated by a program and has a ground-truth answer from a deterministic reference solver.[^1,3] The queries vary K, the number of tool families an agent must chain, from one to four.[^1,3]

The agent has to arrive at an exact numerical or spatial result.[^1] An exact match scores full credit.[^1] Otherwise a language model judges the answer element by element.[^1] A deterministic offline scorer is also supplied, giving partial credit for near-miss numbers and string overlap.[^1]

The public release holds 85 development queries from 19 templates.[^1] The 210-query test split, from 72 templates, is held back.[^1] Code is under Apache 2.0 and data under CC BY 4.0, with Google Maps data excluded from both.[^1] The authors ask that the benchmark not be used as training data.[^1]
