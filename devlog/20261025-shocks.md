## Notes (Claude; precedents from memory, verify before any public use)

- **Most of these shocks are grey swans, not black.** Taleb's black swan is the one nobody could have named in advance. A bird flu that adapts to mammals is a named risk with an unknown date; it is on Nextstrain's front page. A twin can carry a list of named shock types with rough frequencies and severities, even when it cannot say when one will come.
- **The technique already exists elsewhere.** Insurers run catastrophe models over thousands of simulated years of storms and earthquakes and read off the loss in the bad years. Bank regulators run stress tests against a set adverse scenario. Both ask "does the system survive this?" rather than "what will happen?". That is the question a place twin can ask too: inject the shock, watch what breaks first.
- **The game exists in pieces.** SimCity has had random disasters since the first version. The board game Pandemic is cooperative play against outbreaks. Tabletop exercises in public health are rehearsals of a shock with real officials. The wiki's Communication shelf already has role-play games (World Climate, companion modelling); none of them is built around surprise.
- **What a game adds.** Players who know a shock will come, not which one, start buying slack: storage, spare capacity, redundancy, relationships. That is resilience made visible, and it is hard to show any other way, because in normal years slack looks like waste.
- **Link to what the wiki has.** Tipping points and the regime shifts database are the slow version (a system pushed until it flips); shocks are the fast version (a system hit from outside). The "knowing where it breaks" use in 20261024-what-is-it-for.md covers both.
